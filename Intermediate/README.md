# Intermediate Level – Store Sales and Profit Analysis

## Objective
To analyze the Sample Superstore dataset using Python and understand sales and profit performance.

## Dataset
- Dataset: Sample Superstore
- Total Records: 9,994
- Total Columns: 21

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Tasks Performed
1. Data loading and exploration.
2. Data cleaning and preprocessing.
3. Checking missing values.
4. Sales and profit analysis.
5. Category-wise sales and profit analysis.
6. Region-wise sales and profit analysis.
7. Data visualization using graphs.
8. Monthly sales trend analysis.
9. Business insights.

## Key Results
- Total Sales: 2,297,200.86
- Total Profit: 286,397.02
- Total Quantity Sold: 37,873

## Project File
`ShadowFox_Store_Sales_Analysis.ipynb`

## Conclusion
This project helped analyze store sales and profitability using Python and data visualization techniques.
